# @nextide/ui

Shared Nextide React components and product interface patterns, built with
shadcn/ui, Base UI, Tailwind CSS, and React 19.

```bash
pnpm add @nextide/ui
```

Import the shared theme once in your app, then use explicit package exports:

```tsx
import "@nextide/ui/globals.css"
import { AppShell } from "@nextide/ui/blocks/app-shell"
import { Button } from "@nextide/ui/components/button"
```
